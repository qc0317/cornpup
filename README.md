# C++ 趣味编程 · 第一课

面向小学生的静态学习网页，主题为“让我们愉快地开始吧！”。

## 内容

- 第一课原视频播放、调速、全屏及下载
- 全部 12 页课件预览、原 PPT 与 PDF 下载
- 编程与计算思维的入门介绍
- 4 × 4 机器人指令挑战（顺序执行，不是 C++ 编译器）
- 认识编辑、编译、运行与工具准备清单
- 三题即时反馈小测，本机浏览器进度与探索徽章

## 查看

直接用浏览器打开 `index.html`，不需要安装依赖。样式和脚本在该文件内；视频和课件位于 assets/。请保留完整目录。

## GitHub Pages

将 `index.html`、`assets/` 和 `.nojekyll` 放在仓库根目录。进入仓库 **Settings → Pages → Build and deployment**，选择 **Deploy from a branch**，分支 **main**，目录 **/(root)**，点击 **Save**。以 Pages 显示的实际地址为准。

## 资料说明

依据提供的《小学生 C++ 趣味编程》第 1 课时 PPTX 整理改写。机器人挑战和课堂小测是新增活动。原课中的开发工具版本与竞赛环境描述可能已过时，网页不沿用其“最新版本”或竞赛指定环境的断言。包含用户指定的第一课原视频、原课件及静态预览；不包含教材或安装文件。

学习进度只保存在本机 localStorage；限制浏览器存储时页面仍可使用，但刷新后进度可能丢失。
